      Design · what runs where

      Observe, remember, evaluate, react

      Each chain checks what it can see, inside every allocation, with no wait. The reactive contract on Lasna holds what no single chain can see and pushes it to both. Tap a box to see its role and address.

      AI reasons, code enforces and Reactive reacts, so the agent can sleep while the reaction logic stays active.

      Evidence · tests, attacks, mutants

      How it is tested

      Integration tests run on a real Touchstone deployment from its own factory, and we replay the Reactive side from exact LogRecords. Every attack test has a control that must win once the defence is removed, so a passing attack test shows that the defence is what stops it.
